# PARO — Android preview

PARO is a language-learning app for Pashto and Dari speakers.

## Download

Get **PARO.apk** from the [latest release](https://github.com/ggbxdark11-star/PARO-app/releases/latest).

## Install

1. Open the downloaded `PARO.apk` on your Android phone.
2. If asked, allow installing apps from this source (browser or Files app).
3. Tap **Install**, then open PARO.

## Good to know

- This is a **preview build** for testing. It is signed with a test key, so a
  later store version will need this one uninstalled first.
- The app works while the PARO test server is online. If it cannot connect,
  the server is offline for now — try again later.
